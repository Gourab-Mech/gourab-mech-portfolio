# Gourab Mech — Portfolio

A single-file responsive portfolio website with animated introduction and dedicated information pages for Dhemaji Engineering College and Jawahar Navodaya Vidyalaya.

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub, for example `gourab-mech-portfolio`.
2. Upload the contents of this folder to the repository root (make sure `index.html` is in the root, not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Set branch to `main` and folder to `/(root)`, then click **Save**.
6. Wait for GitHub Pages to finish building. The public address will usually be `https://YOUR-USERNAME.github.io/gourab-mech-portfolio/`. Replace `YOUR-USERNAME` with your GitHub username.

The site uses externally hosted logos and photos on its institution pages, so those images require an internet connection and their source servers must remain available.
